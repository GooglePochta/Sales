# 🏷️ Мобильное приложение «СкидкаМаркет» (Android APK / PWA)

Полноценное мобильное приложение для скидок в магазинах и управления персональными дисконтными картами.

## ✨ Основные возможности:
1. **Витрина скидок и акций**: товары со скидками от -30% до -50%, старая и новая цена, фильтры по категориям (Продукты, Одежда, Электроника, Красота) и мгновенный поиск.
2. **Мои карты для кассы**:
   - Готовые карты популярных магазинов (Пятёрочка, Магнит, Перекрёсток, Спортмастер).
   - Возможность добавить карту любого другого магазина.
   - Генерация контрастного штрихкода на весь экран, считываемого лазерными и фото-сканерами на любых кассах.
3. **Корзина с расчетом выгоды**:
   - Автоматический подсчёт сэкономленных денег («Вы сэкономили: ... ₽»).
   - Промокоды: введите `SUPER20` (-20%), `SKIDKA10` (-10%) или `EXTRA300` (-300 ₽).
   - Накопление бонусных баллов за покупки.
4. **Работа офлайн**: данные карт сохраняются в памяти устройства, штрихкоды открываются даже без интернета прямо в торговом зале.

## 📱 Как получить APK файл и установить на телефон:

### Вариант 1 (Самый простой — без установки программ, онлайн):
1. Опубликуйте этот проект (или загрузите папку) на бесплатный хостинг (например, [Vercel](https://vercel.com), [Netlify](https://netlify.com) или GitHub Pages).
2. Перейдите на сайт **[PWABuilder.com](https://www.pwabuilder.com/)** (официальный сервис Microsoft).
3. Вставьте ссылку на сайт и нажмите **«Build My APK»**.
4. Сервис сгенерирует готовый файл **`.apk`**, который можно сразу скачать и установить на любой Android-смартфон!

### Вариант 2 (Автоматическая сборка через GitHub Actions):
1. Загрузите файлы репозитория в свой GitHub.
2. Файл `.github/workflows/build-apk.yml` автоматически запустит бесплатный облачный сервер Ubuntu с Android SDK.
3. Через 2-3 минуты во вкладке **Actions -> SkidkaMarket-Debug-APK** будет готов файл `app-debug.apk` для скачивания.

### Вариант 3 (Локальная сборка через Android Studio):
1. Установите Node.js и Android Studio.
2. В терминале выполните:
   ```bash
   npm install
   npx cap add android
   npx cap open android
   ```
3. В открывшемся Android Studio нажмите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.

### Вариант 4 (Установка прямо сейчас как приложение без APK):
Откройте `index.html` в браузере Chrome на смартфоне -> нажмите три точки в меню -> **«Добавить на главный экран»** (или «Установить приложение»). Приложение появится на рабочем столе с собственной иконкой и будет работать автономно.
